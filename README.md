# Brightline Dental — concept clinic website

Concept website for a **fictional** dental clinic. Designed and built by Nafis A.

- 3-step online booking: service → date & time → details, with validation and confirmation
- Live "Open now / Closed" status and today's hours highlighted
- Service cards that open a details dialog, with "Book this" pre-selecting the service
- Pricing plans, team, map, FAQ; fully responsive with a mobile menu
- Plain HTML, CSS and JavaScript

Brightline Dental, its team and address are not real. No booking data is sent anywhere.
